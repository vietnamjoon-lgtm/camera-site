# 포토부스 설계 (1단계)

2026-11-16 확정. 2단계(네 컷), 3단계(얼굴 스티커)는 1단계를 써 본 뒤 따로 설계한다.

## 목표
카메라 화면에 왜곡·색 효과를 씌워서 사진을 찍고, 드라이브에 자동으로 올리는 포토부스.
아이폰·아이패드·맥 어디서나 쓴다. 사진은 기기에 저장하지 않고 드라이브에만 올린다.

## 화면 흐름
1. 시작 버튼 → 카메라 켜짐, 거울처럼 좌우 반전해서 크게 보여 줌
2. 효과 버튼 → 3×3 격자에 효과 9개 실시간 미리보기, 2페이지(총 18개). 누르면 그 효과로 전환
3. 셔터 → 3·2·1 카운트다운, 흰 번쩍임, 찰칵 소리
4. 화면에 보이는 그대로(반전된 모습) JPEG로 드라이브 녹화 폴더에 `photobooth_날짜_시간.jpg` 업로드.
   구석에 방금 찍은 사진 썸네일, 업로드되면 ✅

## 효과 (18개)
- 왜곡: 볼록 렌즈, 오목 렌즈, 소용돌이, 좌우 거울, 상하 거울, 가로 늘리기, 세로 늘리기, 물결, 어안 렌즈
- 색: 원본, 흑백, 세피아, 만화, 열화상, 픽셀, 팝아트, 네온 윤곽선, 색 반전

## 구조
- WebGL 프래그먼트 셰이더 하나가 효과 하나. 격자 모드는 한 캔버스에 칸마다 viewport를 나눠 그린다.
- `photobooth/effects.js`: 효과 목록 (id, 이름, GLSL 몇 줄). 효과 추가는 여기에 한 항목.
- `photobooth/renderer.js`: WebGL 준비, 카메라 텍스처, 한 칸 그리기
- `photobooth/app.js`: 화면 흐름 (시작, 격자, 카운트다운, 촬영, 업로드)
- 업로드는 `../recording.js`의 `saveRecording` (기존 Apps Script, 기존 폴더)

## 배포
새 공개 저장소 `camera-site` + GitHub Pages → `https://vietnamjoon-lgtm.github.io/camera-site/photobooth/`

## 확인
- 맥 Chrome에 가짜 카메라 영상을 넣어 효과별 화면을 찍어 본다 (`?auto&effect=<id>`, `?auto&grid=<페이지>`)
- 드라이브에 JPEG가 실제로 올라가는지 확인
- 아이폰·아이패드는 사용자가 직접 확인
